My First Day at eHealth Africa Academy

📅 Published: June 12, 2026 | By Salim Bello Muhammad

I still remember the excitement I felt on my first day at eHealth Africa Academy in Kano. I had always been curious about technology and how websites and apps were made, but I never had a structured path to learn. That all changed when I joined the UI/UX Design programme.

The first module was about setting up my environment installing Visual Studio Code, learning about GitHub, and writing my very first HTML page. Something as simple as seeing my name appear in a browser window for the first time felt like a massive achievement. It was the moment I realized that coding was not as intimidating as I had imagined.

"Every expert was once a beginner. The journey of a thousand miles begins with a single step." Lao Tzu

The mentors at eHealth Africa Academy were incredibly supportive from day one. They broke down complex concepts into simple, understandable pieces and made sure no one was left behind. I was nervous at first, but the learning environment was warm, encouraging, and practical.

💡 What I learned on Day 1: How to install VS Code, set up Live Server, write basic HTML structure, and push code to GitHub for the first time.

Discovering the Power of UI/UX Design

📅 Published: June 20, 2026 | By Salim Bello Muhammad

A few weeks into the programme, we shifted from coding to design and this is where everything truly clicked for me. I had always appreciated beautiful websites and apps, but I never knew what went into creating them. Learning about UI (User Interface) and UX (User Experience) design opened my eyes to a completely new world.

We started with wireframing in Figma creating low-fidelity sketches of app screens. My first project was a simple to-do app with just two screens: a home screen showing a list of tasks, and a detail screen showing information about a specific task. It might sound simple, but the process of thinking through how a user would interact with the app was genuinely fascinating.

"Design is not just what it looks like and feels like. Design is how it works." Steve Jobs

One of the most important things I learned was about visual hierarchy making sure the most important information on a screen is the most visible. This principle changed the way I look at every website and app I use. I started noticing design decisions everywhere the size of buttons, the color of links, the spacing between elements.

I also learned about accessibility designing for everyone, including people with visual impairments. Checking color contrast ratios on WebAIM and adjusting my coral color from #D85A30 to #B34A22 to meet WCAG AA standards was a real-world lesson that stuck with me.

💡 Key lessons from this phase: Wireframing in Figma, visual hierarchy, color contrast (WCAG AA minimum 4.5:1), component-based design, and responsive layouts for mobile and desktop.

Building My First Webpage with HTML & CSS

📅 Published: July 15, 2026 | By Salim Bello Muhammad

Coming from a design background (having spent weeks in Figma), moving into actual web development with HTML and CSS felt like bringing my designs to life. There is something incredibly satisfying about writing code and seeing a styled webpage appear in your browser knowing that YOU built it from scratch.

My first major HTML/CSS project was a travel webpage about Dubai. I used CSS to style everything from the golden header color to the hover effects on navigation links. I learned about selectors, font properties, margins, padding, and how to arrange elements on a page. What surprised me most was how much control CSS gives you over every tiny detail of a webpage's appearance.

"The details are not the details. They make the design." Charles Eames

I also built a Hausa Traditional Recipe Book which was personally meaningful to me because it celebrated the food and culture of my home in Kano, Nigeria. Using HTML tables for ingredients, ordered lists for cooking steps, and internal links for the table of contents made the page feel like a real, professional website.

Looking back at where I started a blank HTML file with just my name in an h1 tag and comparing it to what I can build now, I feel an enormous sense of pride and progress. This journey has shown me that with consistency, curiosity, and the right guidance, anyone can learn to design and build for the web.

💡 Projects completed so far: Personal introduction page, to-do app wireframes, profile screen, responsive dashboard, mini style guide, Dubai travel webpage, Hausa recipe book, JavaScript greeting and grade calculator, and the HealthBridge healthcare web app concept.
